# MI PORTAFOLIO

¡Hola! 👋 Soy Keissy Daiana, estudiante de Tecnología en Programación de Software en el SENA y apasionada por el desarrollo web y el diseño de interfaces.
Este repositorio contiene mi portafolio web personal, un proyecto creado para presentar quién soy, mis habilidades, los proyectos en los que he trabajado y los conocimientos que he ido adquiriendo durante mi proceso de formación.
Mi portafolio representa parte de mi crecimiento como desarrolladora y mi interés por crear páginas web modernas, organizadas, atractivas y fáciles de utilizar.

##Tecnologías utilizadas

-HTML5 — Estructura y contenido del sitio.
-CSS3 — Diseño, estilos y adaptación responsiva.
-JavaScript — Interactividad y funcionalidades.

##🚀 Características

-📱 Diseño responsivo para diferentes dispositivos.
-🎨 Interfaz moderna y atractiva.
-👩‍💻 Sección de información personal.
-🛠️ Sección de habilidades.
-📂 Presentación de proyectos.
-📄 Información sobre mi formación y experiencia.
-📬 Sección de contacto.
